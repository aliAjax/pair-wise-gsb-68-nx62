# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- 共享来源库：一个来源可支持多项事实、多条主张，原始证据、二次来源、待证信息分类与内容哈希留档。
- 来源改版/撤下级联：仅依赖它的未发布结论失效待重认，排队发布批次取消；已发布结论保持冻结。
- 发布批次冻结当时来源快照，放行前快照校验，来源随后变化即取消发布。
- 并发提交同一主张只放行先到批次，晚到批次保留输入与双方版本值（跨窗口经本地持久化状态校验）。
- 复合写入先落完整批次日志，本地写入失败后启动时恢复，只补未完成对象，不重复追加版本和审计。
- 旧数据自动迁移：内嵌来源迁入共享库并补登版本，无法确认依赖的事实先标记待核。
- 证据关系图、来源时间线、多人批注和解决状态。
- 发布前校验、版本记录、完整档案与审计导出。

端口为`18468`。

```bash
npm install
npm run build
npm run dev
npm run test:smoke   # 证据链核心行为冒烟测试
```
