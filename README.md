# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、事实结论、置信度和未解决疑点。
- 共享来源库：一份来源可支持多项事实，版本留档与内容哈希，事实按引用角色（支持/反驳）冻结来源快照。
- 来源改版或撤下后，依赖它的未发布结论失效待重认；排队与已发布批次随之取消发布，主张撤回。
- 发布批次：排队时冻结全部来源快照，提交时校验快照与主张版本；两个窗口同时提交同一主张只放行先到批次，晚到批次保留输入与双方值。
- 本地写入失败后从完整批次恢复，只补未完成对象，不重复追加版本和审计。
- 旧数据迁移：内嵌来源迁入共享库并补录版本，无法确认依赖的事实先待核。
- 多人批注、解决状态、完整档案与审计导出。
